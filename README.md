# 像素疗愈小屋 · Pixel Cabin

一个**单文件**的像素风疗愈网页：坐在屋里，窗外是雨夜 / 海边 / 森林 / 炉火，或者你自己导入的一张照片。
16 条环境声各自能开关、各自能调音量，画面会跟着声音动（下雨、浪推、火光跳、树摇、虫飞）。

![预览](docs/preview.png)

> 双击 `index.html` 就能用，不需要安装、不需要服务器、不需要联网。

---

## 功能

**声音（16 条，全部可独立开关 + 独立音量）**

| 类型 | 内容 |
| --- | --- |
| 录音 13 条 | 细雨、雨打窗、大雨、海浪、溪流、瀑布、水滴、风声、林间风、风铃、鸟鸣、夏夜虫鸣、篝火 |
| 实时合成 3 条 | 白噪音、粉红噪音、棕噪音（Web Audio 现场生成，不是录音） |

- 每个场景默认只开 4 条，13 条全开太吵，不疗愈。
- 切换场景时声音交叉淡化，不会硬断。
- 刷新页面不会自动出声，必须点「播放」。

**场景 × 时刻（两排独立，可任意组合）**

- 场景：雨夜 / 海边 / 森林 / 炉边 / 我的窗外（导入照片后出现）
- 时刻：晨 / 昼 / 昏 / 夜
- 天空、太阳、月亮、星星、云按时刻分别绘制；月亮只在夜里出现。
- 太阳在晨/昏会低垂到地平线上。

**声音驱动画面**

| 打开的声音 | 画面反应 |
| --- | --- |
| 雨类 | 窗外落雨；雨打窗时玻璃上挂水珠 |
| 海浪 / 溪流 / 瀑布 / 水滴 | 窗下水带、浪推、瀑布、落水 |
| 风 / 林间风 | 树摇、气流掠过、风铃摆 |
| 鸟鸣 / 虫鸣 | 飞鸟、草丛萤火 |
| 篝火 | 壁炉火光跳动、火星上升、房间暖光呼吸 |

**房间（代码绘制的占位场景）**

- 两层结构：**窗外层**（116×100 画布，可被照片替换）+ **房间层**（320×180 画布，床 / 壁炉 / 台灯 / 窗框 / 猫）。
- 屋内彩蛋：点台灯、点壁炉（会真点着）、摸猫（单击「喵～」，连点三下「呼噜噜～」）。
- 空格键 = 播放 / 暂停。

**照片导入（全部本地处理，不上传）**

- 拖拽 / 选择文件 / `Ctrl+V` 粘贴，三种都行。
- 可调：颗粒粗细、颜色数量、明暗、对比度、颜色浓淡、清晰度，左边实时预览。
- 自动按颜色与构图猜画面类型（天空 / 水面 / 植被 / 夜景 / 灯光），给出带数字的依据，并明确标注**「这是猜测，不是真的认出了内容」**。
- 按猜测推荐 3~5 条声音并说明理由，可以不采用，也可以之后随时改。
- 时刻调色对照片同样生效：夜里会重新染成深蓝夜景（暗部染夜色、亮部保留暖光），不是简单调暗。
- 参数与缩小后的照片（约 26KB JPEG）存在浏览器 `localStorage`，**刷新后还能继续调、能重新应用**；原图不会保存。

## 快速开始

```bash
# 方式一：直接双击 index.html（推荐，file:// 下音频可正常播放）

# 方式二：起个本地静态服务（可选）
python -m http.server 8000
# 然后打开 http://localhost:8000
```

首次打开请点一次「播放」——浏览器要求用户手势才允许出声。

## 实现要点

- **不用 Web Audio 接 mp3**：`file://` 下 `createMediaElementSource` 会被浏览器按跨域处理而静音，双击就没声了。所以录音走 `<audio>` + 逐帧补间 `volume` 实现淡入淡出；只有合成噪音用 Web Audio。
- **画面是两张低分辨率画布**，CSS `image-rendering: pixelated` 放大，像素颗粒感来自这里，不靠滤镜。
- **照片管线**：cover 裁切 → 逐级减半降采样 → 明暗/对比/饱和 → 时刻调色 → 锐化 → 颜色量化 → 最近邻放大；预览用的就是窗外层本身，所见即所得。
- **音量安全**：起播前把音量归零重新淡入，播放键带单次开关锁，连点不会叠；切到后台自动暂停，回来不会自己响。

## 兼容性

现代 Chromium / Firefox / Safari（需支持 Canvas 2D、Web Audio、`backdrop-filter`）。
`localStorage` 在 `file://` 下各浏览器策略略有差异，若照片无法保存，改用本地静态服务打开即可。

## 已知限制

- 画面是**占位场景**（代码绘制），不是照片级写实；窗外层可随时更换。
- 照片分析是**颜色与构图的启发式猜测**，遇到低反差、大面积单色的照片会猜不准——猜不准时面板会直接说"不好判断"，此时按耳朵选声音更靠谱。
- 13 条录音全开会很吵，默认只开 4 条。
